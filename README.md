# Excel-Project

## 1. E-commerce Store Dashboard

Interactive Excel dashboard analyzing 31K+ retail order records to uncover monthly sales trends, customer demographics, product performance, order status, and sales channel insights using Pivot Tables, Charts, and Slicers.

## 2. Customer Shopping Analytics Dashboard

Interactive Excel dashboard analyzing 99K+ customer transactions to uncover revenue trends, customer demographics, shopping mall performance, payment preferences, and product category insights using Pivot Tables, Charts, and Data Visualization techniques.
